# 🎮 Tic-Tac-Toe Game

A fully responsive **Tic-Tac-Toe** game built with **HTML**, **CSS**, and **Vanilla JavaScript**. This project demonstrates core web development skills including DOM manipulation, event handling, responsive design, and game logic implementation.

---

## 🚀 Features

- 🎯 Two-player functionality
- 🏆 Winner & draw detection logic
- ✨ Smooth UI with hover effects
- 🔄 Reset & New Game buttons
- 💡 Visual highlight for winning moves
- 📱 Responsive on tablets and desktops
